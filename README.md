## Meta Conversions API

Job-application clicks from Facebook or Instagram ads are sent server-side to Meta dataset `2115299572705878`. Configure the generated Events Manager token as the server-only environment variable `META_CONVERSIONS_ACCESS_TOKEN`.

For Events Manager verification, temporarily set `META_CONVERSIONS_TEST_EVENT_CODE` to the code shown under **Test Events**. Remove it after the production event has been verified so later conversions are recorded as live events.
